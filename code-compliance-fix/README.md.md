# Code Compliance Fix

用于检查并修复定制组件项目中源码的部分合规问题。

## 能做什么

- 检查并修复错误码
- 检查并修复日志
- 检查 `logback` 配置
- 清理无效导入并格式化代码
- 检查生产环境配置
- 按需检查依赖和 CVE

处理完成后会再次检查，并在对话中给出简短汇总。

## 使用范围

仅适用于定制组件的 Java 项目。

只处理合规问题，不修改业务逻辑、接口行为、数据库设计、项目架构等。

如果需要检查代码质量、业务逻辑、性能或架构时，应使用专门的 Code Review Skill 或 Agent。

## 什么时候使用

适合以下场景：

- 老代码迭代后，需要满足新的合规要求
- 新代码提交前，进行合规检查
- 项目交付或发布前，统一检查错误码、日志和配置
- HIDO 安全扫描后，处理指定依赖漏洞

## 怎么使用

在项目源码中直接执行：

```text
检查并修复当前项目的合规问题。
```

需要检查依赖时明确说明：

```text
检查并修复当前项目的合规问题，同时检查无效依赖和 CVE。
```

依赖检查默认不执行。

## 怎么扩展

本 Skill 默认仅支持5类检查，实际上不同框架、不同行业，有不一样的合规要求，可以进行扩展。新增规则时，直接修改 Skill 中对应章节。

新增规则应说明检查范围、什么情况不合规、怎么修复、怎么复检

扩展范围应限制在错误码、日志、代码格式、配置等合规明确要求的内容，超出这些范围的能力，建议单独创建 Skill。
