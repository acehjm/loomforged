# Code Scribe

Code Scribe 是一个从源码中提取业务知识的 Skill。

它帮助工程师快速理解和接手已有项目，通过分析源码梳理：

- 项目解决什么业务问题。
- 核心业务流程如何运行。
- 关键业务规则和边界。
- 数据如何流转。
- 系统如何与外部服务协作。

Code Scribe 的目标不是生成源码说明，而是建立准确、可验证的业务认知。

---

# 核心原则

优先理解业务，再组织文档。

分析过程围绕：业务入口、核心流程、业务规则、数据变化、外部协作展开。且所有结论应基于源码事实，避免经验推测。

---

# 适用场景

适用于：

- 快速理解陌生项目。
- 接手已有系统。
- 梳理项目业务流程。
- 从源码生成或完善 README。
- 沉淀项目业务文档。

更适合业务逻辑复杂、存在流程和系统协作的企业级项目。

不适用于：

- 纯 UI 项目。
- 简单 CRUD 项目。
- SDK 或通用组件库。
- 单纯算法代码仓库。

---

# 输出内容

生成的 README 以业务知识为中心，重点包括：

- 项目概况。
- 业务入口。
- 核心业务流程。
- 业务规则与边界。
- 数据流转。
- 外部系统协作。
- 必要的配置和接口说明。

不强调源码目录、类结构或无业务价值的代码说明。

---

# 扩展

README 内容组织由 `presentation.md` 控制，可修改自定义内容输出。

如需适配其他平台输出，可通过对应的 `<platform>-export.md` 定义导出格式。
