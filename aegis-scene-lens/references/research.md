# 行业、政策与证据研究

仅在用户要求行业/政策研究，或关键结论依赖可能变化的外部事实时使用。先完成场景定界，再围绕用户要作出的决定建立研究问题。

## 研究范围

按需研究以下内容，不做无关的宏观资料汇编：

- 行业运行机制、主要风险和责任体系。
- 当前有效的法律、政策、监管要求和标准。
- 与目标业务直接相关的现行实践和统计数据。
- 会改变能力需求、实施边界或可行性结论的外部事实。

## 来源顺序

优先使用：

1. 法律法规数据库、政府和监管部门。
2. 标准正式发布或查询机构。
3. 公共事业单位、权威统计和行业主管单位。
4. 同行评议论文、大学和公共研究机构。
5. 方法透明的行业协会和专业研究。

新闻、论坛、转载和营销材料仅用于发现线索；关键结论由官方或独立来源支撑。

## 政策核验

每份决定性文件记录：

| 字段 | 内容 |
|---|---|
| 文件 | 官方全称及类型 |
| 机构与日期 | 发布机构、发布日期和实施日期 |
| 状态与层级 | 现行、修订、废止、征求意见；强制或推荐 |
| 适用范围 | 地域、行业、对象、触发条件和例外 |
| 关键要求 | 仅概括与场景直接相关的内容 |
| 业务影响 | 映射到职责、流程、数据、建设或运营 |
| 来源 | 原始链接和检索日期 |

区分强制义务与鼓励方向、全国要求与地方试点、现行文件与征求意见稿、合规底线与最佳实践。涉及个人信息、生物特征、车牌、音频、定位、轨迹或公共视频时，核验当前有效的数据和视频管理规则，只说明潜在适用性，不替代法律审查。

## 证据与冲突

标记关键结论：

- `已核实`：直接、有效且适用的一手证据。
- `较强推断`：多个来源支持，但未直接覆盖当前场景。
- `工作假设`：等待现场或用户验证。
- `未知`：证据不足。

决定性事实尽量由两条独立证据交叉验证；法规原文等唯一权威来源除外。来源冲突时比较层级、日期、地域、定义和适用条件，呈现仍无法消除的分歧并降低置信度。

引用放在其支持的结论附近，链接原始页面，使用绝对日期。统计数字同时说明口径、样本、地域和年份。公开证据不足时，指出需要通过现场调研、台账、访谈、抽样观察或 PoC 补齐的内容。

**完成条件**：每个会改变结论的外部主张都有来源、日期、适用范围和证据状态；冲突、局限及现场证据缺口已明确。
