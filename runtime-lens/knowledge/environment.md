# Environment

## 测试环境公共特征

- 测试环境用于本地开发、联调和故障排查。
- 服务器为 Linux，可能是 x86_64、aarch64、银河麒麟或 UOS；具体系统与架构以现场查询结果为准。
- 平台通常安装在 `/opt/hikvision`，少量老平台安装在 `/opt/opsmgr`。
- Nginx 位于 `cluster` 组件中，负责入口转发。
- 本地源码通常直接连接测试环境中的服务。

组件、服务、实例和日志的公共规则见 [Platform Layout](./platform-layout.md)。

## 目标环境

不同测试环境只存在 SSH 连接差异，不重复维护平台路径和服务清单。本地源码中的 `@bic.bic.ip` 表示测试环境 SSH IP；其他业务 IP、项目名称和目录名称不能作为环境匹配依据。

除 `@bic.bic.ip` 提供的 SSH IP 外，本地源码配置中的服务地址、端口、URL 和部署路径只代表本地开发调用方式，不与测试环境运行态共用。测试环境的 PID、监听端口、进程、路径和状态必须以远端现场查询结果为准；本地端口未监听不能作为测试环境服务未运行的证据。
