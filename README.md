# LoomForged
A Knowledge-Centric framework: structure first, clarity follows.
一套 Knowledge-Centric 框架——先建立结构，再生成清晰认知。
## About
LoomForge 是一套方法论，用于将零散、碎片化的输入锻造为结构化、可信赖的知识产出。每个技能都是这套方法论的一次具体落地。
## Skills

field-notes —— 整理零散文本内容整理为结构化知识
code-scribe —— 逆向代码生成文档
prd-craft —— 建立需求边界，生成 PRD 文档

## Philosophy
结构先行，产出在后；技能间彼此解耦；持续生长，不限定形态。
