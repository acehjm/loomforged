# Engineering

- 保护调用前已有或来源不明的用户修改，不回退、不覆盖、不擅自提交。
- 实现写入只发生在 `phase: work`，并严格落在 active Task 的 `Scope`。
- 先理解现有接口、约定和测试，再做满足 Goal 的最小完整修改。
- 不加入当前 Goal 没有证明需要的抽象、兼容层或额外产物。
- 不删除、跳过或弱化测试，不吞掉错误，不伪造 Evidence。
- 外部写入必须由 Goal 授权，并在实际执行时获得用户确认。
- `goal.md` 和 `work.md` 是唯一常驻治理状态；普通任务不创建图、Spec、Todo、Issue 或进度副本。
