# 规格说明书

> 本文件是开发与测试的规范性契约，每个开发 Goal 固定存在一份。用户没有提供规格时，通过开放式访谈形成；用户已经提供接口文档、需求或规格时，通过规格压力测试补全。原始资料仍是输入证据，本文是归一化后的实施与验收依据，不复制成第二套 Goal。

`source_mode` 只能在确认前收敛为：`discovery`（开放式访谈）、`pressure_test`（已有资料压力测试）或 `hybrid`（两种方式并用）。本文件不维护独立确认状态；`goal_confirmation` 一次共同封存 `goal.md + spec.md`。确认后若本文件发生实质变化，必须撤销确认并返回 `clarifying`。
