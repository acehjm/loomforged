# wali-0x3 品牌与虚拟形象

## 品牌构成

`wali-0x3` 是通用虚拟开发团队及其协作系统的正式名称，负责承载团队架构、角色协作、任务调度、开发执行、审查测试和经验沉淀等能力。

`waliwali` 是 `wali-0x3` 的虚拟形象，用于承担头像、人格表达、对外沟通和品牌展示。它不是具体的调度 Agent，也不对应某一个开发角色，而是整支团队面向使用者的统一形象。

```text
wali-0x3
通用虚拟开发团队及其协作系统

waliwali
wali-0x3 的虚拟形象与对外人格
```

对外介绍可以使用：

> waliwali，由 wali-0x3 驱动的虚拟开发伙伴。

## 名称含义

WALI 代表：

> **Work · Assign · Loop · Inspect**

对应团队的核心工作方式：

```text
Work
明确需要完成的工作，建立目标、范围和验收标准。

Assign
拆解并分配任务，让合适的 Agent 认领和执行。

Loop
围绕目标持续开发、审查、测试和修复，直到满足完成条件。

Inspect
检查实现结果、测试证据和问题状态，确认工作是否真正完成。
```

中文可以概括为：

> **明确工作、分配任务、循环执行、检查结果。**

这四个动作构成 `wali-0x3` 的基本协作闭环：

```text
Work
明确目标
   ↓
Assign
拆解与分配
   ↓
Loop
开发、审查、测试与修复
   ↓
Inspect
检查结果与验收条件
   └──────── 未完成则重新进入 Loop
```

WALI 不只是名称解释，也可以作为团队执行时的基本检查顺序。任何一轮工作开始和结束时，都可以用这四个问题进行确认：

```text
Work
当前工作和完成标准是否清楚？

Assign
任务是否已经交给合适的角色？

Loop
开发、审查、测试和修复是否形成闭环？

Inspect
是否有足够证据证明目标已经完成？
```

## 品牌关系

`wali-0x3`、`waliwali` 和各类 Agent 的关系如下：

```text
wali-0x3
├── 团队协作系统
├── 角色与任务机制
├── 开发、审查和测试闭环
└── 全局经验沉淀
     │
     └── waliwali
         ├── 统一虚拟形象
         ├── 对外沟通人格
         ├── 视觉与内容表达
         └── 团队品牌代表
```

各 Agent 是 `wali-0x3` 内部承担具体职责的执行角色，例如调度、前端、后端、审查和测试。`waliwali` 不取代这些角色，也不参与角色职责划分。

## 使用边界

以下场景使用 `wali-0x3`：

- 项目名称、仓库名称和目录标识。
- 团队架构和协作机制说明。
- Agent、Skill、规则文件和命令体系。
- 技术文档、开发配置和系统日志。
- 团队能力与运行状态描述。

以下场景使用 `waliwali`：

- 头像、插画和虚拟形象。
- 面向使用者的欢迎语和提示语。
- 产品界面中的团队代表。
- 对外介绍、演示和品牌内容。
- 未来可能扩展的性格、语气和故事设定。

不建议使用 `waliwali` 作为项目根目录、技术包名或调度 Agent 的名称，以免虚拟形象和系统组件混淆。

## 当前定位

现阶段品牌定位保持简单：

> `wali-0x3` 是一支目标驱动、文件协作、角色分工、持续验证的通用虚拟开发团队。

> `waliwali` 是这支团队友好、稳定且可信赖的虚拟形象。

品牌形象暂不预设复杂的世界观、性格标签或视觉规范。后续可以结合实际使用体验，逐步补充形象外观、表达语气、标志、配色和使用场景。
