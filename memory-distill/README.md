# Memory Distill

将 AI 协作过程中产生的高价值经验沉淀下来，形成可长期复用的经验资产库（Experience）。

## 为什么需要

日常使用 AI 时，会产生很多有价值的内容，比如：解决问题的方法、已确认的设计决策、项目经验、工作方法、开发踩坑等等。但这些内容通常只存在于某一次对话中，换项目、换工具后很难继续使用。

Memory Distill 希望解决：让一次工作中产生的有效经验，可以被未来的 AI 和用户继续复用。

## 和 Agent 记忆的区别

Agent（Claude Code、Codex 等）自带的记忆主要解决：当前工具如何记住上下文，更好的管理工具本身的全局记忆。

Memory Distill 解决：如何跨工具、跨项目沉淀长期有效经验。它不保存完整聊天记录，而是只保留经过整理和筛选的经验。

## 如何使用

在完成重要工作后，可以主动要求：

- “整理一下本次工作的经验”
- “把这个方案沉淀到经验库”
- “检查一下有没有值得长期保存的内容”
- “提取项目所有会话整理经验”

或者使用斜杠命令主动调用，也可以结合 Agent 的自动化能力，如全局注入、Hooks 机制，在任务结束时触发整理。

## 经验资产库

使用一个独立的经验资产库（Experience）保存内容。它不依赖具体的 AI 工具，只要访问的是同一个经验库，都可以继续积累和使用。

```text
experience/
├── index.md
├── scan-state.json
└── memory/
    ├── agent-design.md
    ├── requirement-analysis.md
    └── software-engineering.md
```

**如何调取经验库内容**，在对话中使用 `memory-recall` Skill，或者直接说 “看看有没有类似的经验”，Agent 都会去经验库查询相关经验，根据相关度展示，作为当前会话的参考。

未来可以进一步连接到个人知识库、团队经验库、行业知识库。
