# Memory Distill

从当前会话中提炼真正值得长期保留的工作记忆。

目标不是保存完整对话，而是保存少量、明确、稳定、以后仍然有用的结论。

## 使用场景

当出现以下情况时使用：

* 用户要求记录、沉淀或保存当前会话中的有效内容
* 当前会话形成了明确决策或重要设计取舍
* 某个问题已经找到并验证了有效解决方式
* 对话中形成了可以在后续任务中复用的方法
* 明确了长期有效的项目约束或工作偏好
* 一次排查、失败或调整形成了可复用经验
* 当前任务结束前需要检查是否存在值得长期保留的内容

## 核心原则

### 少而准确

没有高质量内容时，不写入任何记忆。

不得为了完成沉淀任务而强行生成内容。

### 一个记忆只表达一个结论

相互独立的决策、问题或经验，应拆分为不同记忆。

不得将整次会话压缩为一条宽泛总结。

### 只保存已经确认的内容

只保存明确事实、用户确认的决策或已经验证的经验。

未经确认的方案、推测和冲突内容不得进入长期记忆。

### 保留真实来源

尽可能记录工具提供的真实会话标识。

无法获取时应明确标记，不得自行生成或猜测来源标识。

## 不负责的内容

本 Skill 不负责：

* 保存完整聊天记录
* 保存普通问答或临时任务状态
* 保存未经确认的头脑风暴
* 跨工作空间检索和引用历史记忆
* 修复或重建损坏的全局索引
* 将记忆直接发布到个人知识库

## 执行规则

执行时必须读取并遵循：

* `storage.md`：定位全局记忆库和逻辑工作空间，生成标识，按照统一格式写入记忆文件并维护全局索引
* `memory-update.md`：判断什么值得沉淀，以及如何处理跳过、更新、新增和替代

不得在未读取这两个文件的情况下修改全局记忆。

## 执行流程

### 1. 定位逻辑工作空间

按照 `storage.md`：

* 定位全局记忆目录
* 识别当前逻辑工作空间
* 在满足条件时创建新的逻辑工作空间

无法唯一识别逻辑工作空间时，停止写入，不得猜测。

### 2. 提取候选记忆

按照 `memory-update.md`，从当前会话中识别可能具有长期价值的内容。

只处理当前会话，不主动重新整理其他历史会话。

### 3. 判断处理方式

在当前逻辑工作空间中查找相关记忆，并按照 `memory-update.md` 确定处理方式：

* 重复内容跳过
* 实质补充更新已有记忆
* 独立结论新增记忆
* 新结论明确推翻旧结论时执行替代
* 无法确认的内容不写入

不得无条件追加。

### 4. 写入记忆

按照 `storage.md`：

1. 为新增记忆生成标识
2. 按统一格式更新工作空间记忆文件
3. 确认记忆正文写入成功
4. 更新全局索引

必须先写入记忆正文，再更新索引。

### 5. 返回结果

完成后只返回必要信息：

```markdown
记忆沉淀完成：

- 工作空间：field-notes（ws-39bc7a）
- 新增：2 条
- 更新：1 条
- 替代：0 条
- 跳过：3 条
```

没有符合要求的内容时：

```text
本次会话未发现适合长期沉淀的高质量内容，未修改全局记忆。
```

无法确定逻辑工作空间时：

```text
未写入记忆：当前环境无法唯一匹配逻辑工作空间，请明确指定 workspace_id。
```

全局记忆目录不可用时：

```text
未写入记忆：全局记忆根目录不存在、无法访问或结构异常。
```

存在未确认内容时，可以简要说明未写入原因，但不得将其保存为长期记忆。
